# was pinned (cutoff 2026-10-01 for this file's first version, 2026-10-15). Crates are pinned by
# Entropy/Cargo.lock and supply-chain/. The Makefile includes this file (make syntax): it fetches
# Buildroot by BR_URL and refuses it unless it has BR_SHA256, and `make source` and `make image`
# check every *_PINS entry ("hash file:SHA-256:file") against the hash file that Buildroot reads,
# so this record cannot drift from what is built. Until the M7 audit the hashes are checked, the
# sources not reviewed.
